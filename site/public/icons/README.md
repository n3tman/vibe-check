Project icons, one per slug: `<slug>.svg`, `.png` or `.webp` (square, at most 64 KB, 128 px or
more for raster). Self-hosted: the site never loads icons from forges or CDNs. Each file's origin
and licence is recorded in the project's YAML under `icon` (see `docs/schema.md`). Projects without
a file get a generated monogram.
