## How the files were made
- Blobless clones in `cache/repos/<slug>/`, read with `git show` / `git ls-tree` / `git log`; no
  repo code was run.
- AI dev usage: agent files from `git ls-tree` (paths under `vendor/` and `node_modules/` are
  ignored: Honoroit, emm, MRS vendor Go modules that ship their own `CLAUDE.md` etc.), and
  commits of the last 365 days whose message has an AI `Co-authored-by` trailer or a
  "generated with" line, plus AI bot authors (`copilot-swe-agent[bot]`). Bots (dependabot,
  renovate, github-actions, …) are left out of the denominator. The collector will recount.
- One rule needs lane 7's eye: when attributed commits exist but are under 1 % (Ketesa: 1 of
  337), the file says `occasional` and the evidence says it is below the threshold.
- AI policy: CONTRIBUTING, PR templates, CODE_OF_CONDUCT, README and docs grepped for AI terms,
  and the GitHub issue search for AI/LLM/ChatGPT/Copilot/Claude per repo. Only Meowlnir has a
  stated policy (`restricted`, from the mautrix contributing guide). Draupnir has an open
  maintainer issue about an LLM policy (#990), not adopted, so `none-found` with a note.
- GitHub's per-repo REST API is blocked in this environment (proxy answer: "GitHub access to
  this repository is not enabled for this session"); the search API works, so stars, archived
  flag and licence came from `search/repositories?q=repo:…`. ma1sd did not come back from
  search, so its archived flag and stars are unknown.

## Open questions and schema gaps
- matrix-hookshot and matrix-rss-bridge call themselves bridges but sit on the integrations list
  only; filed as bots. Lane 7 may want a "bridge-like" tag.
- Licence `-only` vs `-or-later` is often not stated in the LICENSE file; files say so in notes.
  matrix-eno-bot: matrix.org says WTFPL, the LICENSE file is Apache-2.0 (file used).
- Schema: the bot features `purpose`, `framework`, `hosting`, `config` and `ai_backend` carry
  free text in `value` (not yes/no), with `how` and `source`. Tools use the same keys.
- A field for "multi-network" bots (opsdroid, botdarr, LangBot) where Matrix is one adapter
  among many would help the site.
- Meowlnir's e2ee value rests on the docs only; the code was not checked.
