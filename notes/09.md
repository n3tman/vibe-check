### mirage.yaml (lane 3's file): corrections from reading the repo at `9a4ababd9aa59bd78ad239422918c2c4eaaf6b7d`
Lane 3's values come from pattern matches; several are wrong or have stronger evidence:
- `licence`: **LGPL-3.0-or-later**, not GPL-3.0-only. Every source file carries
  `SPDX-License-Identifier: LGPL-3.0-or-later` (e.g. `src/backend/backend.py` line 2) and
  `packaging/mirage.appdata.xml` says `<project_license>LGPL-3.0-or-later</project_license>`.
  The repo ships both `COPYING` and `COPYING.LESSER`.
- `maturity`: README says "**currently in alpha**" (README.md#L16); `unmaintained` is fine as our own
  reading, but say so in notes.
- `reactions`: **no**, not yes. The `m.reaction` hit at `src/backend/matrix_client.py#L153` is in
  `no_unknown_events_filter`, the list of event types the client *hides* unless
  `Chat.show_unknown_events` is set (applied at matrix_client.py#L502-L506). Reactions only appear
  as a push-rule label (`src/gui/Utils.qml#L588`). Moment added reaction display in 0.7.4.
- `room_upgrades`: **no**, same reason: `m.room.tombstone` is in the same hidden-events filter
  (L152); Utils.qml#L585 is only the push-rule label "Room migration alerts".
- `multi_account`: **yes**, claimed: "**Multiple accounts** in one client" (README.md).
- `moderation_tools`: **yes**, claimed and code: "Kick, ban and set the power level of users"
  (README.md#L53), `src/gui/Popups/RemoveMemberPopup.qml#L24` (`room_ban` / `room_kick`).
- `key_backup`: **partial**: "Import/export **E2E** key files" (README.md#L40,
  `src/gui/Dialogs/ExportKeys.qml`); no server-side key backup found.
- `cross_signing`: not-found is right (no cross-signing code); sessions are verified manually.
- `push_notifications`: partial: desktop notifications plus a push-rules editor (README); no pusher.
- `url_previews`: partial: "Client-side Matrix & HTTP URL **image previews**" (README.md#L74); no
  link (OpenGraph) previews.
- `default_homeserver`: none. The sign-in page has an empty server field (placeholder
  "example.org") and a server browser fed by `https://publiclist.anchel.nl/publiclist.json`
  (`src/backend/backend.py#L554`). The `homeserver="https://matrix.org"` default in
  `MatrixClient.__init__` is a constructor default, not what the UI offers.
- `distribution`: AppImage and a `.flatpak` bundle on the GitHub releases page (not on Flathub:
  `flathub.org/api/v2/appstream/io.github.mirukana.mirage` is 404), AUR `matrix-mirage`, nixpkgs
  `mirage-im` (docs/INSTALL.md). `platforms`: INSTALL.md says "Instructions and releases are currently
  only available for Linux, but compiling on Windows and macOS should be possible": so linux only
  for `apps`.
- `fork_friendliness`: Python + QML, about 470 files, qmake, five git submodules, matrix-nio from the
  author's own fork (`requirements.txt`: `git+https://github.com/mirukana/matrix-nio`), LGPL-3.0.
- `ai`: agree with none-found on all three axes (no agent files, no AI trailers in the whole history,
  no LLM SDKs). I could not search the GitHub issues: the GitHub API and web are not reachable from this
  session for repos outside it. The collector should confirm the archived flag.
- `notes`: "Continued as Moment" is right: Moment's history contains Mirage's last commit
  `9a4abab` unchanged.

### moment.yaml (lane 3's file): corrections from reading the repo at `2667256dbbc940154e9cb3e95b8db5e0b3206393`
- `fork_of: mirage` is right. Evidence: README "Moment is based on Mirage, see differences
  [here](docs/MIRAGEDIFF.md)"; the GitLab description "A Matrix client; forked from Mirage"; Mirage's
  HEAD `9a4ababd` is an ancestor of Moment's `main`. What Moment adds (docs/MIRAGEDIFF.md and
  docs/CHANGELOG.md): renamed and new default theme and keybindings, config migration from Mirage
  (0.7.3, 2022-01-31); reaction display, proper display of edited messages, server list from
  servers.joinmatrix.org, upstream matrix-nio instead of Mirage's fork (0.7.4, 2024-01-04);
  `:emoji:` shortcodes, `/react`, spoilers (0.7.5, 2024-03-07); option to turn off external media
  previews, off by default (0.7.6, 2025-03-06); per-thread read receipts (commit "fix unread
  threads", 2026-03-08). MIRAGEDIFF also says "Due to access issues, it is unlikely Mirage will
  continue being maintained".
- `licence`: **LGPL-3.0-or-later** (same SPDX headers in all 238 source files), not GPL-3.0-only.
- `maturity`: README says "**currently in alpha**" (README.md#L17); lane 3 has `beta`.
- `threads`: **partial**, not yes: the code only reads `m.thread` relations to send threaded read
  receipts (`src/backend/matrix_client.py#L2864`, `src/gui/Pages/Chat/Timeline/EventList.qml#L625-L637`);
  there is no thread view.
- `edits`: **partial**: received edits are displayed (`src/backend/nio_callbacks.py#L168`, CHANGELOG
  0.7.4 "Display edited messages properly"); sending an edit not found.
- `multi_account`: yes (README.md#L41). `moderation_tools`: yes (README.md#L57,
  `src/gui/Popups/RemoveMemberPopup.qml#L24`). `key_backup`: partial (key file import/export only,
  README.md#L44). `push_notifications`: partial (desktop notifications, push-rules editor).
- `url_previews`: partial: image previews only, and external (http) media previews are **off by
  default** since 0.7.6 (`src/config/settings.py#L192-L197`: `preview_external_media: bool = False`,
  with an IP-leak warning). Worth showing under privacy.
- `default_homeserver`: none: empty server field plus a server browser from
  `https://servers.joinmatrix.org/servers.json` (`src/backend/backend.py#L570`).
- `distribution`: Flathub `xyz.mx_moment.moment` (last release there 0.7.6), AUR `moment` and
  `moment-git` (docs/INSTALL.md). `apps` linux: stores flathub
  (https://flathub.org/apps/details/xyz.mx_moment.moment). INSTALL.md says Linux only, like Mirage.
- Activity: last tag v0.7.6 (2025-03-06); 6 commits in the last 365 days, all by one author; the
  GitLab project's last activity is 2026-08-27 (API). GitLab issues searched for AI, LLM, ChatGPT,
  Copilot, "generated": nothing about AI. `ai` none-found on all three axes agrees with mine.
