### mirage.yaml (lane 3's file): corrections from reading the repo at `9a4ababd9aa59bd78ad239422918c2c4eaaf6b7d`
Lane 3's values come from pattern matches; several are wrong or have stronger evidence:
- `licence`: **LGPL-3.0-or-later**, not GPL-3.0-only. Every source file carries
  `SPDX-License-Identifier: LGPL-3.0-or-later` (e.g. `src/backend/backend.py` line 2) and
  `packaging/mirage.appdata.xml` says `<project_license>LGPL-3.0-or-later</project_license>`.
  The repo ships both `COPYING` and `COPYING.LESSER`.
- `maturity`: README says "**currently in alpha**" (README.md#L16); `unmaintained` is fine as our own
  reading, but say so in notes.
- `reactions`: **no**, not yes. The `m.reaction` hit at `src/backend/matrix_client.py#L153` is in
  `no_unknown_events_filter`, the list of event types the client *hides* unless
  `Chat.show_unknown_events` is set (applied at matrix_client.py#L502-L506). Reactions only appear
  as a push-rule label (`src/gui/Utils.qml#L588`). Moment added reaction display in 0.7.4.
- `room_upgrades`: **no**, same reason: `m.room.tombstone` is in the same hidden-events filter
  (L152); Utils.qml#L585 is only the push-rule label "Room migration alerts".
- `multi_account`: **yes**, claimed: "**Multiple accounts** in one client" (README.md).
- `moderation_tools`: **yes**, claimed and code: "Kick, ban and set the power level of users"
  (README.md#L53), `src/gui/Popups/RemoveMemberPopup.qml#L24` (`room_ban` / `room_kick`).
- `key_backup`: **partial**: "Import/export **E2E** key files" (README.md#L40,
  `src/gui/Dialogs/ExportKeys.qml`); no server-side key backup found.
- `cross_signing`: not-found is right (no cross-signing code); sessions are verified manually.
- `push_notifications`: partial: desktop notifications plus a push-rules editor (README); no pusher.
- `url_previews`: partial: "Client-side Matrix & HTTP URL **image previews**" (README.md#L74); no
  link (OpenGraph) previews.
- `default_homeserver`: none. The sign-in page has an empty server field (placeholder
  "example.org") and a server browser fed by `https://publiclist.anchel.nl/publiclist.json`
  (`src/backend/backend.py#L554`). The `homeserver="https://matrix.org"` default in
  `MatrixClient.__init__` is a constructor default, not what the UI offers.
- `distribution`: AppImage and a `.flatpak` bundle on the GitHub releases page (not on Flathub:
  `flathub.org/api/v2/appstream/io.github.mirukana.mirage` is 404), AUR `matrix-mirage`, nixpkgs
  `mirage-im` (docs/INSTALL.md). `platforms`: INSTALL.md says "Instructions and releases are currently
  only available for Linux, but compiling on Windows and macOS should be possible": so linux only
  for `apps`.
- `fork_friendliness`: Python + QML, about 470 files, qmake, five git submodules, matrix-nio from the
  author's own fork (`requirements.txt`: `git+https://github.com/mirukana/matrix-nio`), LGPL-3.0.
- `ai`: agree with none-found on all three axes (no agent files, no AI trailers in the whole history,

## NLnet's policy, by version
- 1.0, 2025-12-08 to 2026-01-26 (https://nlnet.nl/foundation/policies/generativeAI/archive/): use
  allowed with disclosure and a prompt provenance log; "outcomes purely generated by AI are not
  allowed to be submitted as work eligible for payment".
- 1.1, 2026-01-26 to 2026-10-20 (https://nlnet.nl/foundation/policies/generativeAI/1.1/): the same
  rule with lighter logging; projects whose agreement was signed before 2025-12-08 may agree a
  personalised transparency plan, and "logging is not required retroactively".
- 2.0, from 2026-10-20 (https://nlnet.nl/foundation/policies/generativeAI/2.0/): "It is not allowed
  to use generative AI for producing artefacts of any kind, including code, design, and
  documentation"; read-only use allowed, with disclosure.
- Transition (1.1 page and https://nlnet.nl/foundation/policies/generativeAI/faq/): "grantees from
  concluding programmes (notably NGI Zero Commons Fund, NGI Taler and Fediversity) can opt to
  continue to follow this version (1.1)"; the FAQ also says "There are two general exceptions: for
  projects within NGI Zero programmes, because these were already in flight". So every running
  NGI Zero grant below is recorded as `restricted` (1.1), with the 2.0 value (`banned`) in
  `transition`. This changes the earlier Draupnir and Bromal entries, which said `banned`.
