# Lane 1: collector and site

## Done
- **Collector** (`collector/`, Python, uv, only dependency PyYAML). Per repo: blobless clone or
  fetch in `cache/repos/<host>/<path>`, `git log` on `origin/HEAD` (no merges, committer date,
  `.mailmap` honoured), every metric in `docs/schema.md` "Metrics", per repo and `combined`
  per project (commits de-duplicated by SHA across repos, authors de-duplicated across repos).
  Extra fields: `commits_all`, `issues_sampled`, `issues_responded`, `licence_file`,
  `licence_source`, `languages_source`, `prerelease_tags_365d`, `security_policy_url`, `files`,
  `description`, `api_error`, `issue_response_error`, `loc_error`.
- Bot filter: infrastructure bots (list in `collector/src/vibecheck/authors.py`, written to
  `data/metrics/_collector.json` for the methodology page) are dropped from commits and authors;
  Weblate translation commits too. AI agent bots (Copilot agent, claude[bot], Devin, Jules, …)
  keep their commits (they count as AI evidence) but never count as authors.
- `ai_scan`: agent files (`git ls-tree`, a `.claude/`-style directory reported once), trailers
  and "Generated with" lines, AI bot authors, AI workflows; `suggested_dev_usage` by the rubric
  thresholds. One gap in the rubric: under 1 % attributed with no workflows is reported as
  `occasional` (the share is shown next to it); lane 7 may prefer another reading.
- `telemetry_scan`: SDK names in dependency manifests (a match means "named", not "on").
- `last_tag` skips nightly/beta/rc/dev tags (`prerelease_tags_365d` counts those separately).
- Licence: forge API, else detected from the LICENSE file text.
- Forges: GitHub REST (no GraphQL), GitLab `/api/v4`, Forgejo/Gitea `/api/v1`; SourceHut and
  `other` give nulls with `api_error`. Issue first response: GitHub and Forgejo via repo-wide
  comment lists; GitLab needs auth for issue notes, so it is null anonymously.
- 64 pytest tests (trailers, bot filter, author dedup, bus factor, status thresholds, agent
  files, workflows, telemetry, forge URL shapes, a faked GitHub reader).
- **Site** (`site/`, Astro 5, static, zod validation, self-hosted Inter variable): overview,
  category pages (cards + sortable table, filters for search, activity, platform and mobile,
  each AI axis; state kept in the URL), project pages (stats, AI evidence with the collector's
  numbers, heatmap, weekly bars, authors per quarter, language bar, apps, features with
  evidence, MSCs, health signals, repos), server × MSC matrix, compare (2 to 4, `?p=a,b`),
  methodology (lists the models from this repo's `Co-Authored-By` lines at build time),
  `data.json` (whole dataset, CC BY 4.0), 404. Theme switch (system → light → dark) and AI
  stance switch (Neutral / AI-wary / AI-friendly), both in `localStorage`, set before first
  paint. When the collector's suggested dev usage differs from the hand value, the project page
  says so.
- Checked with Playwright at 390 px and 1280 px in both themes with both stances: no console
  errors, no sideways scroll.
- Workflows: `deploy.yml`, `refresh.yml` (calls deploy, because a push with `GITHUB_TOKEN`
  does not trigger other workflows), `ci.yml`.

## Not done / known limits
- **GitHub API untested live.** In this Claude Code session the GitHub REST API answers only for
  this repository (403 elsewhere) and GraphQL is blocked, so GitHub repos got `api_error` here and
  null stars/issues/languages. The reader is unit-tested against the documented response shapes;
  it will run for real in the `refresh.yml` workflow. Lane 7 in a session will hit the same
  403s: run the collector with `--no-api` there (git metrics, AI and telemetry scans still work)
  and let the workflow fill the API fields, or trigger `refresh.yml` by hand after merging.
  Languages for GitHub repos then come from scc (`languages_source: scc`).
- Runtime: `--per-host 1` (CLAUDE.md) means GitHub repos go one at a time. Element X's three
  repos took about a minute with lines of code. A few hundred repos may take hours on the first
  run; `refresh.yml` has a 340-minute limit and caches `cache/repos/` between weeks. If it times
  out, run with `--no-loc` or split with `--only`.
- No SourceHut API (its GraphQL needs a token).
- Ideas not started: changelog of data changes, RSS feed, a spec-version view, fork-friendliness.
