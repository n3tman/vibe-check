What failed or was skipped:
- gitlab.com answered 429 to the per-project lookups and asked for a wait of 41 minutes, then
  another hour on the retry: 151 gitlab.com repositories (from links) have no description, stars
  or date and stay in the list undated. Rerunning the command later fills them from the API (the
  rest comes from the cache).
- Python on Windows rejected Codeberg's certificate chain through an expired intermediate in the
  system store; the command takes `SSL_CERT_FILE` to use a CA bundle alone.
- Forks are left out of GitHub search results (its default). Self-hosted forges are read only
  when linked; their topics aren't searched. SourceHut has no topics and no API reader here.
- Links to forges outside the known list (cgit, self-hosted Gitea without "gitea" in the host
  name, …) aren't taken.
- awesome lists on other forges and lists not named "awesome" (Awesome-Decentralized-Messaging
  covers more than Matrix) weren't read.
